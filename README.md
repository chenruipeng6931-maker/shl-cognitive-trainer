# SHL 认知能力训练器

求职笔试刷题网页。

[SHL](https://www.shl.com/) 是一种认知能力测试，很多外企、咨询、银行、快消的校招笔试会用到。题目主要是图形推理、时间安排、图表分析、日历推算这几类，限时作答。

这个项目把七种题型做成了可以反复练的交互网页：75 道题，按类型单练或整卷限时模拟，交卷有解析。

双击 `index.html` 就能用，不用装东西也不用联网。

题库来源是自己整理的 SHL 练习题，图形和交互全部用 SVG 重画，页面上没有截图。

---

## 题型

| 题型 | 交互方式 | 题量 |
|---|---|---|
| 图形序列 | 点区域填色，补出下一帧 | 15 |
| 时间安排 | 拖任务块到时间轴，或点时段 | 10 |
| 日历排期 | 在月历上点出符合条件的日期 | 13 |
| 数字图表 | 拖饼图扇区 / 柱状图 / 折线图描点 | 22 |
| 标签归类 | 把徽章拖到对应位置 | 12 |
| 节点连线 | 拖住一个点连到另一个 | 2 |
| 组合变换 | 点按钮改箭头，选出能让两边一致的组合 | 1 |

---

## 功能

**训练模式**：一题一判，交了就出结果，附解析（关键规律 / 推导过程两段）。记每题用时。

**模拟考试**：24 题 36 分钟。可抽全部题，也可只抽没做过的或做过的。中途不给反馈，交卷后统一批改，出分题型报告。

**中英双语**：右上角切换，题干有中文翻译，人名公司名保留英文。切语言不丢进度。

**记录**：最近 7 天正确率、今日用时、平均每题用时、累计用时。存在 `localStorage`，首页可清空。

## 改题

```
pdfbank/*.js   （配置源）
    ↓  python3 build/build_db.py
data/bank.db   （SQLite）
    ↓  导出
pdfbank/bank.js（前端加载）
```

改一道题，改 `data/bank.db` 或对应的配置源，跑 `build_db.py` 重新生成 `bank.js`，前端不用动。

## 判分规则

- 时间：误差 0.01 小时以内
- 饼图：差 2% 以内
- 其他：精确匹配
- 连线：排除题目预置的线，只比用户新增的

详细规则见 [JUDGING.md](JUDGING.md)。
